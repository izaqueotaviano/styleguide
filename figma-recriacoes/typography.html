Notas de fidelidade. Os valores em px vêm das variáveis reais do arquivo; a composição de cada estilo (peso + size + line-height) veio das definições de style do Figma. Três divergências no arquivo original foram corrigidas aqui para o material não induzir a erro:

  • A coluna Heading / Leading repetia os nomes …-size em vez de …-line-height; usei os nomes de line-height.
  • Heading XL aparecia como ont-heading-xl-size, sem o “f”.
  • Os dois primeiros estilos usavam ambos font-style-heading; o primeiro está aqui como font-style-heading-large.
As fontes Anthropic Sans e Anthropic Serif não são públicas — o CSS as declara primeiro e cai para um stack equivalente do sistema.
